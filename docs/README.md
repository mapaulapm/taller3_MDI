# Taller 3

## Integrantes

- Maria Paula Pérez Meléndez

## Descripción

Este repositorio contiene la solución de los ejercicios propuestos en el taller 3. Cada punto fue implementado en Python de manera independiente, y separados en subcarpetas según el tipo de ejercicio (criptografía,booleano,cuantica,grafos).

---

## Requisitos

- Python 3.10 o superior
- No se requieren librerías externas; únicamente se utilizan módulos estándar de Python (`heapq`, `random`, `copy`, etc.).

---

## Ejecución

Desde la carpeta principal del proyecto:

```bash
cd src
python nombre_del_archivo.py
```

Por ejemplo:

```bash
python punto_4.py
```

Cada programa solicita por consola los datos necesarios para ejecutar el algoritmo correspondiente.

---

## Ejercicios implementados

- Punto 1. cifrado césar
- Punto 2. rsa
- Punto 3. Computación Multipartita (MPC).
- Punto 4. Algoritmo de Dijkstra.
- Punto 5. Análisis del cierre de estaciones y conexiones.
- Punto 6. Coloreo de grafos.
- Punto 7. Tablas de verdad y circutos lógicos
- Punto 8. Simplificación de funciones booleanas y quine-McCluskey
- Punto 9. Entropía de Shannon
- Punto 10. Simulador cuántico de un qubit

---

## Pruebas

En la carpeta `tests/` se incluyen capturas de pantalla de la ejecución de cada ejercicio, mostrando los datos de entrada y los resultados obtenidos.
